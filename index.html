How It Works

01

Install VS Code + Chrome Companion

Grab the lightweight extension from the VS Code Marketplace and the Chrome Web Store. Both talk locally via an encrypted loopback port.

02

Open Your Projects Normally

Work like you always do. DevTabs associates whatever tabs you open (localhost, PRs, docs, Figma) with your active workspace folder automatically.

03

Switch Folders & Watch Chrome Follow

When you switch VS Code windows or open another folder, your Chrome window collapses inactive tabs and expands the exact tab group for that project.
